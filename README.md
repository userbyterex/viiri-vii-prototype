# Viiri VII: Parasite Core (Web Prototype)

Un prototipo de RPG estilo FF7 en ambiente Cyberpunk + Fantasía Oscura diseñado para ejecutarse en la nube / navegador web.

## Estructura del proyecto
- Motor: Godot Engine 4 (Compatibility Renderer)
- Despliegue automático: GitHub Actions -> GitHub Pages

## Cómo jugar en local
Abre la carpeta en Godot 4 y ejecuta con F5.
