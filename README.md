# Viiri VII: Parasite Core

**Prototipo jugable** de un JRPG cyberpunk + fantasía oscura inspirado en *Final Fantasy VII*.

> Un joven espadachín infectado por un parásito biomechanical lucha en las calles inferiores de **Oakhaven Prime** contra las fuerzas de la corporación que lo creó.

---

## Cómo jugar

### En el navegador (recomendado)
El prototipo se despliega automáticamente en GitHub Pages con cada push a `main`.

### En local
1. Abre el proyecto con **Godot 4.2+**
2. Pulsa **F5**

---

## Características del prototipo actual

- Combate por turnos con 3 acciones significativas
- Sistema de **Parásito / Infección** (riesgo-recompensa)
- **Limit Break** (Core Despertar)
- Enemigo biomechanical con comportamiento reactivo
- Identidad visual y narrativa más clara
- Código limpio y preparado para expandir

---

## Visión del juego completo

**Viiri VII** aspira a ser un JRPG de escala media con:
- Combate por turnos profundo (estilo FF7 + sistemas modernos)
- Mundo cyberpunk decadente con magia tecnológica
- Historia dramática centrada en identidad, parasitismo y resistencia
- Party de 3-4 personajes memorables

Este repositorio contiene únicamente el **prototipo de combate** (Fase A).

---

## Controles del prototipo

| Botón | Acción |
|-------|--------|
| **1. Blade Slash** | Ataque con espada. Genera Limit y poca Infección |
| **2. Parasite Slash** | Ataque potenciado. Sube bastante la Infección |
| **3. LIMIT BREAK** | Solo disponible al 100%. Daño masivo + purga parcial de Infección |

La **Infección** es poder y maldición. A mayor nivel, más daño infliges... pero también más riesgoso se vuelve el combate.
