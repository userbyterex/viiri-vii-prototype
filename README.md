# Viiri VII: Parasite Core (3D Prototype)

Prototipo 3D de combate por turnos estilo JRPG cyberpunk.

## Cómo abrirlo

1. Abre la carpeta con **Godot 4.2+**
2. Pulsa **F5**

## Controles

- **1. Blade Slash** → Ataque básico
- **2. Parasite Slash** → Más daño + sube Infección
- **3. LIMIT BREAK** → Solo al 100%. Daño masivo

## Estado actual

- Escenario 3D básico (plataforma industrial)
- Vesper y Sentinel como placeholders 3D
- Sistema de combate completo (Infección + Limit Break)
- Cámara fija estilo JRPG
- UI superpuesta

Próximos pasos posibles: animaciones reales, mejores modelos, efectos, más enemigos, exploración.
